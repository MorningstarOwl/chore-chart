# Changelog

## 1.0.0

- First release as a Home Assistant add-on: sidebar panel through ingress, plus port 8420
  for phones and tablets without a Home Assistant login. Data in the add-on's folder, so it
  is part of Home Assistant backups.
- Includes everything in the chart so far: month and week calendars, rooms, everyday and
  scheduled chores (weekly, monthly, quarterly, yearly, every N days) with overdue
  carry-over, per-person daily goals, the weekly Scores page with rewards, critter icons,
  and light/dark mode.
